## 調査の内容 {#method}

{{< feature-grid variant="tile" >}}
{{< feature wsicon="wifi" title="電波と不具合を同時計測" headingLevel="h3" >}}受信専用の計測器で電波を記録しながら、通信と機器の状態も同じ時刻で残し、不具合の瞬間を捉えます。{{< /feature >}}
{{< feature wsicon="report" title="その場で解析・対策" headingLevel="h3" >}}従来は持ち帰っていた詳細な解析を、独自の計測・解析環境によりその場で行い、原因と対策を提案します。{{< /feature >}}
{{< feature wsicon="users" title="現場に合わせて柔軟に調査" headingLevel="h3" >}}機材やシステムに合わせて手順を組み、担当者と協力して詳しく調べ、対策を試して確かめます。{{< /feature >}}
{{< /feature-grid >}}

**特徴**: 電波を同時に見ることで、時間と労力のかかる原因の切り分けを、現地で早期に実現します。

**体制**: 物理 (電磁波)・ネットワーク・機械系のフィールドエンジニア 1〜2 名が、計画から現地、解析、報告までを一貫して担当します。現地では貴社の担当者と協力して切り分けを進め、設定変更などの試行は同意のもとで一緒に行います。

## 対象になる装置と無線 {#targets}

**実績のある領域**

- 重機の遠隔操作 (オペレーター側と機械をつなぐ無線、安全系の無線)
- 遠隔操作・監視のための映像配信 (低遅延の配信、拠点間の回線、現場側の中継装置)

**同じ手法で切り分けられる対象**

- AMR / AGV (Wi-Fi のローミングやチャンネル退避、棚や機械による遮蔽)
- 工場の自動化ロボット (無線の操作端末、生存信号のタイムアウト)
- ドローン (地上局周辺の電波の混雑)
- 港湾・物流拠点の遠隔クレーン (ローカル 5G、コンテナによる反射)
- 農業機械の自動運転 (位置補正情報の途絶)

**計測できる周波数の範囲**: 70 MHz〜6 GHz (ローカル 5G / LTE の sub-6、Wi-Fi 5 GHz / 2.4 GHz、サブギガ帯、400 MHz 帯・150 MHz 帯の業務無線を含みます)。有線 LAN / WAN (MTU、経路) も調査の対象です。

## よくある質問 {#faq}

{{< accordion >}}
{{< accordionItem title="守秘はどうなりますか" >}}
パスワード等のクレデンシャル、パケットの中身、お客様の実装内容、お客様とそのお客様の情報、お客様が特定される情報は守秘します。事前に共有していただく資料は調査の目的以外に使いません。守秘契約の雛形を用意しています。急ぎで現地に入る場合は、調査を先に始め、守秘契約を調査開始日にさかのぼって締結することもできます。

一方で、匿名化した技術的な問題そのもの (症状・原因・対策の考え方) と、調査を通じて弊社が自然に得るノウハウは、他の現場への事業展開のため、守秘の範囲外とさせていただきます (守秘契約の雛形に明記します)。これらに制約がかかると、他のお客様の現場で同じ種類の問題を解決できなくなるためです。お客様や関係者が特定される情報は含めません。ご理解をお願いします。
{{< /accordionItem >}}
{{< accordionItem title="約束できないことはありますか" >}}
EMC 試験や適合試験のように、規格値に対する合否を判定することを目的としたサービスではありません。計測は不具合の切り分けを目的とし、相対比較と時刻の対応を中心に行います (校正された絶対値が必要な場合はご相談ください)。Wi-Fi のフレーム単位の解読は、必要な場合に専用の機材を事前見積で手配します。電波を出す再現試験 (アクセスポイントの持ち込み、負荷の生成) は行いません。調査中に一度も起きなかった現象は、原因の特定が難しくなります。待機は予備日で対応し、特定できなければ最低料金のみです。
{{< /accordionItem >}}
{{< accordionItem title="事前に用意するものは" >}}
ネットワーク構成とシステムの要約 (共有できる範囲で)、ログや動画。共有を依頼する内容の雛形を用意していますので、生成 AI にその雛形を渡して、共有可能な情報をまとめていただくと効率的です。現地では、必要に応じて、貴社担当者による不具合動作の立会い、調査・検証のための設定変更の同席、立入手続き、受信専用の計測機器の持ち込み許可をお願いします。
{{< /accordionItem >}}
{{< accordionItem title="予備日とは何ですか" >}}
予備日 3 日は、現場の状況に応じたトラブルシュートや、不具合の発生頻度に対する余裕として、事前に弊社内で予定を確保するものです。予備日を使わなかった場合も基準額は変わりません。
{{< /accordionItem >}}
{{< accordionItem title="基準額のほかに費用はかかりますか" >}}
全国の現場にお伺いするため、交通費・宿泊費は基準額に含めず、実費を同じ請求書で別途ご請求いたします。調査項目の追加や、予備日を超える追加の測定のご要望がある場合は、1 項目または 1 日あたり 10 万円を目安にご相談いたします。危険を伴う現場や夜間の作業も、1 件あたり 10 万円を目安にご相談ください。第三者に提出する正式な報告書や特殊な機材が必要な場合は、別途お見積りいたします。調査内容によって料金が変わる場合は、お見積り時にお伝えいたします。
{{< /accordionItem >}}
{{< accordionItem title="導入前の電波環境調査 (サイトサーベイ) はできますか" >}}
現場への装置導入前の電波環境調査 (サイトサーベイ) は 25 万円でお受けいたします。遠隔操作の装置を新しく導入する場合や、調べるべき通信の帯域がはっきりしている場合に向いています。導入前に、その帯域の電波の混み具合や妨害の有無を現地で測り、注意点をお伝えします。
{{< /accordionItem >}}
