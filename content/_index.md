## 調査の内容 {#method}

電波・通信・機器の状態を **同時に測り**、不具合が起きた瞬間と照らし合わせて、その直前に何が起きていたかを突き止めます。

{{< feature-grid >}}
{{< feature icon="search" title="電波の計測" headingLevel="h3" >}}受信専用の計測器で、利用している帯域に、いつ・どんな周期で電波があるかを記録します。外部からの妨害電波の有無も同時に確かめます。{{< /feature >}}
{{< feature icon="globe" title="通信の挙動の確認" headingLevel="h3" >}}ping、パケットの取得、機器の設定確認で、途切れの長さと周期、パケットの大きさに依存する損失、到着間隔の乱れ (ジッタ) を調べます。{{< /feature >}}
{{< feature icon="list-check" title="機器のログとの照合" headingLevel="h3" >}}不具合が起きた時刻と計測結果を照らし合わせ、原因となる機器・設定・環境を名指しして、その場でできる対策を現場の担当者と一緒に試します。{{< /feature >}}
{{< /feature-grid >}}

潜在する原因にたどり着くための切り分けは難しくても、特定できれば解決の手段は設定の変更 1 つなど簡単なことも少なくありません。そのため、原因の特定に力点を置いています。

報告は、**A. 原因を特定した** (対策と、対策後の確認結果) / **B. 疑った原因は検出されなかった** (何をどこまで測ったかと、次に疑うべき方向) / **C. 判定できなかった** (足りなかった条件と、次に必要な計測) の 3 パターンで実施します。

電波の計測は受信のみを行い、電波の発信は行いません。問題の切り分けや解決の試行のために、担当者の同意のもと、お客様の機器の設定変更などを一緒に行うことがあります。電波の空き状況は時間とともに変わるので、不具合が起きている **その場・その時** に測ります。

## 対象になる装置と無線 {#targets}

**実績のある領域**

- 重機の遠隔操作 (オペレーター側と機械をつなぐ無線、安全系の無線)
- 遠隔操作・監視のための映像配信 (低遅延の配信、拠点間の回線、現場側の中継装置)

**同じ手法で切り分けられる対象**

- AMR / AGV (Wi-Fi のローミングやチャンネル退避、棚や機械による遮蔽)
- 工場の自動化ロボット (無線の操作端末、生存信号のタイムアウト)
- ドローン (地上局周辺の電波の混雑)
- 港湾・物流拠点の遠隔クレーン (ローカル 5G、コンテナによる反射)
- 農業機械の自動運転 (位置補正情報の途絶)

**解析実績のある無線・回線の例**: Wi-Fi 5 GHz、Wi-Fi 2.4 GHz、サブギガ帯 (920 MHz 帯など) の特定小電力無線、有線 LAN / WAN (MTU、経路)。

**計測できる周波数の範囲**: 現在の計測器で 70 MHz〜6 GHz (ローカル 5G / LTE の sub-6、Wi-Fi 5 GHz / 2.4 GHz、サブギガ帯、400 MHz 帯・150 MHz 帯の業務無線を含みます)。一度に観測できる幅は 4 MHz です。

## よくある質問 {#faq}

{{< accordion >}}
{{< accordionItem title="守秘はどうなりますか" >}}
パスワード等のクレデンシャル、パケットの中身、お客様の実装内容、お客様とそのお客様の情報、お客様が特定される情報は守秘します。事前に共有していただく資料は調査の目的以外に使いません。守秘契約の雛形を用意しています。急ぎで現地に入る場合は、調査を先に始め、守秘契約を調査開始日にさかのぼって締結することもできます。

一方で、匿名化した技術的な問題そのもの (症状・原因・対策の考え方) と、調査を通じて弊社が自然に得るノウハウは、他の現場への事業展開のため、守秘の範囲外とさせていただきます (守秘契約の雛形に明記します)。これらに制約がかかると、他のお客様の現場で同じ種類の問題を解決できなくなるためです。お客様や関係者が特定される情報は含めません。ご理解をお願いします。
{{< /accordionItem >}}
{{< accordionItem title="約束できないことはありますか" >}}
EMC 試験や適合試験のように、規格値に対する合否を判定することを目的としたサービスではありません。計測は不具合の切り分けを目的とし、相対比較と時刻の対応を中心に行います (校正された絶対値が必要な場合はご相談ください)。Wi-Fi のフレーム単位の解読は、必要な場合に専用の機材を事前見積で手配します。電波を出す再現試験 (アクセスポイントの持ち込み、負荷の生成) は行いません。調査中に一度も起きなかった現象は、原因の特定が難しくなります。待機は予備日で対応し、特定できなければ最低料金のみです。
{{< /accordionItem >}}
{{< accordionItem title="事前に用意するものは" >}}
ネットワーク構成とシステムの要約 (共有できる範囲で)、ログや動画。共有を依頼する内容の雛形を用意していますので、生成 AI にその雛形を渡して、共有可能な情報をまとめていただくと効率的です。現地では、必要に応じて、貴社担当者による不具合動作の立会い、調査・検証のための設定変更の同席、立入手続き、受信専用の計測機器の持ち込み許可をお願いします。
{{< /accordionItem >}}
